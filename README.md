# Two Player Dice Game

A simple two-player dice game built with Python and Tkinter.

## Features

- Two players: TOTO and TITI
- Animated dice rolling
- Alternating turns
- Running score totals
- First player to reach 50 points wins
- Reset game button

## Requirements

- Python 3
- Tkinter

Tkinter is included with most standard Python installations, so no extra Python packages are required.

Run in PowerShell:
python .\dice_gui.py

## How to Play

1. Click **Play Turn**.
2. TOTO rolls first.
3. TITI rolls next.
4. Players continue taking turns.
5. Each roll is added to that player's total.
6. The first player to reach 50 points wins.
7. Click **Reset Game** to start a new game.
